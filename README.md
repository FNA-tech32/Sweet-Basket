# Sweet Basket

Sweet Basket is a React storefront for browsing seasonal collections, product categories, and popular items. The homepage shows a promotional announcement, navigation with search and a cart, a hero slider, category highlights, a product grid, a newsletter signup, and a footer with brand, links, and contact details.

## Features

- Announcement bar for the current shipping offer
- Navigation with language selection, search, register, sign in, and a cart badge
- Hero slider for the summer sale, autumn collection, and loungewear
- Category highlights for shirt style, loungewear, and light jackets
- Popular product grid
- Newsletter signup
- Footer with the Sweet Basket brand, useful links, and contact details

## Getting started

Install dependencies, then start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the store. `npm start` runs the same development server.

## Scripts

- `npm run dev` or `npm start` runs the app in development and reloads on changes
- `npm run build` creates an optimized production build in the `dist` folder
- `npm run preview` serves the production build locally
